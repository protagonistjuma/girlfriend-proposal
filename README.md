# Will You Be My Girlfriend?

An interactive girlfriend proposal made especially for Trinah.

The experience begins with the big question, then turns her “yes” into a small celebration planner: food choices, a date and time, intentionally ridiculous girlfriend terms and conditions, and a shareable confirmation receipt.

## Features

- **Interactive proposal**: A playful “Will you be my girlfriend?” question for Trinah.
- **Celebration planner**: Choose food plus the date and time to come over.
- **Funny T&Cs**: A tongue-in-cheek girlfriend agreement before making it official.
- **Shareable receipt**: Send the plan over WhatsApp or export it as an image.
- **Responsive design**: Built for both phones and desktops, with reduced-motion support.

## Technology

The site uses plain HTML, CSS, and JavaScript. Choices are stored in local storage as Trinah moves through the flow.

## Run locally

Open `index.html` in a browser or serve the directory with any static web server. The included `vercel.json` enables clean URLs when deployed on Vercel.
